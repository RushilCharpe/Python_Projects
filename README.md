# 🔢 Number System Converter

A Python-based **Number System Converter** that converts numbers between Binary, Octal, Decimal, and Hexadecimal formats. It features a simple terminal-based user interface with colored output for a better user experience.

## ✨ Features

- 🔹 Convert Binary (Base 2) numbers.
- 🔹 Convert Octal (Base 8) numbers.
- 🔹 Convert Decimal (Base 10) numbers.
- 🔹 Convert Hexadecimal (Base 16) numbers.
- 🎨 Colored terminal output for improved readability.
- ✅ Input validation and error handling for invalid numbers.
- 📊 Displays the original number, input format, output format, and converted result.

## 🛠️ Technologies Used

- **Language:** Python
- **Module:** `os` (for clearing the terminal screen)
- **Concepts:** Conditional statements, exception handling, user input, and built-in number conversion functions.

## 📋 Requirements

- Python 3.x
- A terminal or command prompt that supports Python.

No external libraries are required.
